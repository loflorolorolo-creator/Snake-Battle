# Статус Android-сборки Snake Battle

## Что подготовлено в проекте
- Горизонтальная ориентация и масштабирование под экран.
- Сенсорное управление с виртуальным стиком и кнопкой ускорения, позиции элементов рассчитываются от размера экрана.
- Исправлена обработка паузы: отдельная зона кнопки, без дублирующихся ветвей ввода.
- Боты могут погибать при столкновении головой с головой игрока; столкновение головы игрока с телом бота завершает матч.
- Добавлена цветовая основа четырёх биомов и центральных руин.
- Добавлен Android export preset для тестовой сборки arm64.
- Добавлен GitHub Actions workflow для запуска проверки Godot и экспорта debug APK в CI.

## Чего пока нельзя заявить
- APK ещё не собран.
- Проект не был запущен в настоящем движке Godot в этой среде: здесь нет Godot, Android SDK и Android export templates.
- Workflow и export preset подготовлены, но не прошли удалённый запуск. Их совместимость с конкретной версией образа CI ещё требуется подтвердить.
- Это всё ещё ранний прототип, а не полная игра из согласованного дизайн-плана: нет четырёх полноценных биомов с геометрией, боссов, постоянного магазина/сохранений, полноценных заданий, 50 ботов и финального босса.

## Следующий технический этап
1. Импортировать проект в Godot 4.3.x и устранить ошибки парсера/импорта, если они появятся.
2. Успешно выполнить Android export через preset `Android`.
3. Установить debug APK на физический Android-телефон и проверить поворот/масштаб, касания, паузу, производительность и звук.
4. Только после этого считать APK первой проверенной тестовой сборкой.

## Путь сборки без собственного компьютера
Подготовлен GitHub Actions workflow `.github/workflows/android-debug.yml`. После размещения проекта в GitHub и запуска workflow GitHub должен предоставить APK как downloadable artifact, если контейнер Godot CI и export preset отработают корректно. Для этого потребуется GitHub-репозиторий и подключение/авторизация; сам факт наличия workflow ещё не означает, что APK уже создан.
