# Snake Battle — первая техническая заготовка

Это исходный проект Godot 4 для первой тестовой игровой версии. Он содержит:
- горизонтальную игровую сцену;
- стартовый экран;
- управляемую сегментированную змейку;
- сенсорное управление перетаскиванием слева и экранную кнопку ускорения справа;
- сбор еды, рост и выносливость;
- простых движущихся змей-ботов;
- мини-карту, HUD, паузу и экран завершения матча;
- оригинальную синтезированную фоновую мелодию.

## Как открыть проект
1. Установить Godot 4.3 или более новую версию с поддержкой Godot 4.
2. Распаковать архив.
3. В Godot выбрать Import и указать файл `project.godot`.
4. Запустить проект кнопкой Play.

## Важное ограничение этой сборки
Это ранний игровой прототип, а не завершённая игра из согласованного ТЗ. В этой среде не обнаружены Godot, Android SDK и инструменты экспорта Android, поэтому APK здесь не собран и проект не прошёл запуск в самом движке. Для APK потребуется настроить Android export templates и Android SDK/JDK в Godot.

## Управление в прототипе
- На Android: коснуться стартового экрана; затем вести палец по левой части экрана для поворота.
- Удерживать круглую кнопку «УСКОР» справа внизу.
- Кнопка паузы — круг с символом `Ⅱ` вверху справа.
- На компьютере: стрелки — направление, Space — ускорение, Esc — пауза.
